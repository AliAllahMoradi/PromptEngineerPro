# Prompt Engineer Pro – Android v1.0

نسخه اول مستقل، بدون API و با رابط فارسی.

## امکانات
- دریافت درخواست خام کاربر
- انتخاب حوزه تخصصی و عمق تحلیل
- تعیین رفتار برنامه در برابر ابهام
- تولید پرامپت قاعده‌محور و قابل ویرایش
- کپی پرامپت
- ارسال از طریق Android Share Sheet به ChatGPT یا برنامه‌های دیگر
- ذخیره محلی تا ۵۰ پرامپت با DataStore

## محدودیت‌های نسخه اول
- این نسخه به مدل هوش مصنوعی یا API متصل نیست؛ بنابراین بازنویسی معنایی هوشمند انجام نمی‌دهد.
- برنامه نمی‌تواند متن را مستقیماً داخل کادر گفت‌وگوی اپ ChatGPT تزریق کند. روش استاندارد و قابل اتکا، Share Sheet اندروید است.
- یادگیری خودکار واژگان کاربر در این نسخه وجود ندارد؛ تنظیم حوزه و دستورهای تکمیلی قابل انتخاب است.

## ساخت APK
1. Android Studio را نصب کنید.
2. پروژه را از مسیر `PromptEngineerPro_Android_v1` باز کنید.
3. در صورت درخواست، Gradle Sync را انجام دهید.
4. از منوی Build گزینه Build APK(s) را انتخاب کنید.
5. فایل خروجی معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## پیش‌نیاز
- Android Studio نسخه جدید
- JDK 17
- Android SDK Platform 35
- حداقل Android 8.0 (API 26)

این پروژه در محیط حاضر کامپایل و روی گوشی آزمایش نشده است؛ پیش از انتشار نهایی باید Build و تست دستگاه انجام شود.
